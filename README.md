## A few chapters so far

**[CampusSathi](https://github.com/Manviasawa2005/CampusSaathi)**  
A student-focused project built around making campus information and resources easier to access. Built with Java, and with the very practical hope that finding useful information shouldn't feel like a treasure hunt.

**[Employee Performance Analysis](https://github.com/nikitapoonia06/Employee-Performance-Analysis-System)**  
A look at a 1,000-row dataset, exploring employee performance and workplace attributes. A reminder that data is good at answering questions, but only when you ask the right ones.

**[Marketing Campaign A/B Testing](https://github.com/nikitapoonia06/Marketing-Campaign-AB-Testing)**  
An experiment comparing two marketing groups using statistical testing and effect-size interpretation. The result wasn't a dramatic plot twist: the difference wasn't statistically significant. That's still a result worth understanding.

**[QuizSphere](https://github.com/nikitapoonia06/Quiz-Portal-)**  
A quiz application built with Java and Spring Boot, and another step in getting more comfortable with backend development.
